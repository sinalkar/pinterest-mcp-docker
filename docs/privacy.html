Privacy Policy

Last updated: August 8, 2026

This Privacy Policy describes how pinterest-mcp-docker ("the App", "we", "us") handles information when you authorise it to access your Pinterest account. By using the App, you agree to the practices described in this policy.

1. What This App Is

pinterest-mcp-docker is an open-source Model Context Protocol (MCP) server that connects AI assistants (such as Claude Desktop, Cursor, and custom LLM agents) to the Pinterest API v5. The App is distributed publicly via GitHub, PyPI, and Docker container registries. It is an unofficial project and is not affiliated with, endorsed by, or sponsored by Pinterest, Inc.

The App is designed to be self-hosted by each user on their own machine or container. Each instance operates on a single Pinterest account belonging to the person who configures and runs it.

2. Data We Access

When you authorise the App via Pinterest OAuth 2.0, the App requests the following scopes:

  • boards:read — Read your Pinterest boards
  • boards:write — Create and manage your boards
  • pins:read — Read your pins
  • pins:write — Create, update, and delete your pins
  • user_accounts:read — Read your basic account information

The App provides the following capabilities through the Pinterest API:

  • Create, update, and delete pins on your boards
  • Create, list, and delete boards
  • List pins on a specific board
  • Search public Pinterest pins by keyword
  • Retrieve pin-level and account-level analytics (impressions, saves, clicks, engagement)
  • Retrieve trending topics and keywords

3. How We Use Your Data

All data accessed through the Pinterest API is used solely to:

  • Perform the actions you (or your AI assistant) explicitly request, such as creating a pin or listing boards
  • Retrieve analytics for your own account's performance tracking
  • Search and discover public Pinterest content

We do not:

  • Sell, rent, or share your data with any third party
  • Use your data for advertising purposes
  • Use your data to target people with advertising outside of Pinterest
  • Join or combine Pinterest Data with personal information from other sources
  • Derive or attempt to derive non-public information about individual Pinterest users, including their location
  • Use automated scraping or data extraction methods outside the official Pinterest API
  • Share or sell information from the Pinterest API with another advertising service

4. Data Storage and Retention

4.1 OAuth Tokens

The App stores your Pinterest OAuth 2.0 credentials (access token and refresh token) locally on the machine or container where the App is running. Tokens are saved to:

  • $XDG_STATE_HOME/pinterest-mcp/token.json (if XDG_STATE_HOME is set), or
  • ~/.local/state/pinterest-mcp/token.json (default fallback)

The token file is written with restrictive 0600 file permissions and the parent directory with 0700 permissions to prevent unauthorised access. Token files are never uploaded to any remote server or third-party service.

4.2 No API Response Data Stored

In accordance with the Pinterest Developer and API Terms of Service, the App does not store, cache, or persist any information accessed through the Pinterest API. Each time data is needed (e.g., listing boards, retrieving analytics), the App makes a fresh API call. The only data persisted on disk is the OAuth token file described above.

4.3 Logs

The App produces local log output for operational and debugging purposes. The App automatically redacts known secrets (OAuth access tokens, client secrets, and base64-encoded payloads) from log entries. Logs are stored locally and are not transmitted to any remote logging service.

4.4 Data Retention

OAuth tokens are retained on your local machine only for as long as needed to operate the App. You may revoke the App's access at any time via your Pinterest account security settings. To remove stored tokens from your machine, delete the token file at the path listed in Section 4.1.

5. Third-Party Services

The App communicates exclusively with the official Pinterest API v5 over HTTPS. No other third-party services, APIs, analytics platforms, or advertising networks receive your data. The App enforces TLS certificate verification on all outbound connections.

6. Data Security

The App implements the following security measures to protect your credentials and data:

  • Token file permissions: OAuth tokens are stored with 0600 file permissions and 0700 directory permissions.
  • Atomic writes: Token files are written atomically via temporary files and os.replace() to prevent partial writes or corruption.
  • TLS enforcement: All HTTPS connections to the Pinterest API require valid certificate verification. The App refuses to start if TLS verification is disabled.
  • Secret redaction: Access tokens, client secrets, and base64 payloads are automatically scrubbed from log output and error messages.
  • SSRF protection: Outbound image URL requests are validated against public IP ranges to prevent Server-Side Request Forgery attacks.
  • Path traversal guards: Local image file access is restricted to a configured allowed directory with canonical path verification.
  • Bearer token auth: When running in HTTP server mode on a non-loopback address, the App requires a bearer authentication token for all requests.
  • Container hardening: The Docker image runs as an unprivileged user (UID 10001) with a read-only root filesystem and all Linux capabilities dropped.

7. Your Privacy Rights

7.1 California Consumer Privacy Act (CCPA)

If you are a California resident, the following applies in accordance with the CCPA and the Pinterest Developer and API Terms of Service:

  • No sale of personal information: We do not sell your personal information, as "sell" is defined under the CCPA. Pinterest does not receive any monetary or other consideration from us for your personal information.
  • Purpose limitation: We do not retain, use, or disclose your personal information for any purpose other than for the specific purpose of providing the App's functionality as described in this policy.
  • No disclosure outside business relationship: We do not retain, use, or disclose your personal information outside the direct business relationship between you and the App.
  • Right to know and delete: You have the right to request disclosure of the personal information we collect and to request deletion of that information. Since the App stores only OAuth tokens locally on your machine, you can exercise this right by deleting the token file described in Section 4.1 and revoking access in your Pinterest settings.
  • Right to opt out: Since we do not sell personal information, there is no sale to opt out of. You may revoke the App's access to your Pinterest account at any time.
  • Non-discrimination: We will not discriminate against you for exercising any of your CCPA rights.

7.2 General Data Protection Regulation (GDPR) — EEA Users

If you are located in the European Economic Area (EEA), the following applies:

  • Lawful basis: The App processes your data based on your explicit consent, which you grant by completing the Pinterest OAuth 2.0 authorisation flow.
  • Right to access: You may request information about the personal data we process about you. Since only OAuth tokens are stored locally, you can inspect the token file directly.
  • Right to erasure: You may request deletion of your data by deleting the local token file and revoking the App's access in your Pinterest settings.
  • Right to withdraw consent: You may withdraw your consent at any time by revoking the App's access via your Pinterest account security settings and deleting the local token file.
  • Right to data portability: The OAuth token file is stored in JSON format and can be copied or transferred by you at any time.
  • Data minimisation: The App only requests the OAuth scopes necessary for its functionality and does not access data beyond what is needed for the requested actions.
  • No cross-border transfers: The App runs locally on your machine or container. No data is transferred to servers controlled by the App developer. Data is only transmitted to Pinterest's API servers as governed by Pinterest's own privacy policy.

7.3 Children's Privacy

The App is not intended for use by children under the age of 13. We do not knowingly collect personal information from children under 13. If you believe a child under 13 has provided personal information to the App, please contact us so we can take appropriate action.

8. Data Breach Notification

In the event of a data breach that compromises Pinterest Data or your OAuth credentials, the App's maintainer will:

  • Promptly investigate the incident and take reasonable actions to mitigate harm
  • Notify affected users and Pinterest as soon as reasonably practicable
  • If located in the EEA, notify within two (2) business days of becoming aware of the breach
  • Cooperate with Pinterest to provide any additional information reasonably requested
