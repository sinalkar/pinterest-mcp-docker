Privacy Policy

Last updated: March 8, 2026

This Privacy Policy describes how the Pinterest MCP application ("the App") handles information when you authorise it to access your Pinterest account.

1. What This App Is

Pinterest MCP is a personal developer tool built to automate pin creation and board management on a single Pinterest account owned and operated by the developer. It is not a public service and is not available to third parties.

2. Data We Access

When authorised via Pinterest OAuth 2.0, the App may access:

  • Your Pinterest boards (read and write)
  • Your pins (read and write)
  • Basic account information (username, profile)
  • Pin and board analytics (read only)

3. How We Use Your Data

All data accessed is used solely to:

  • Create new pins on your boards on your behalf
  • Read existing boards and pins to avoid duplicates
  • Retrieve analytics to assess post performance

No data is shared with third parties, sold, or used for advertising.

4. Data Storage

OAuth tokens (access token and refresh token) are stored locally on the developer's own machine in a file named .pinterest_token.json. This file is never uploaded to any remote server or third-party service.

5. Data Retention

Tokens are retained only as long as needed for the automation tasks. They can be revoked at any time via your Pinterest account security settings.

6. Third-Party Services

The App communicates exclusively with the official Pinterest API v5. No other third-party services receive your data.

7. Contact

If you have any questions about this policy, please open an issue on the GitHub repository.
